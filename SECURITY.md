# Reporting security issues

Please don't post vulnerability details, microphone recordings, or private data
in a public issue.

When this repository opens, the maintainer will enable GitHub's private reporting
form at [Report a vulnerability](https://github.com/fcjr/surf/security/advisories/new).
That form is not available while publication is being prepared.

Include the Surf version or commit, reproduction steps, and the impact. Issues
that keep recording after dictation stops or send input to an unintended app are
especially useful to report.
