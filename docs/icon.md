# App icon

The source artwork is in `icon-source.png`. The app uses the PNG sizes in
`Surf/Resources/Assets.xcassets/AppIcon.appiconset`.

Generated with the built-in imagegen tool. The original alpha channel is preserved;
the app icon sizes were exported with macOS `sips`.

## Generation prompt

Use case: stylized-concept

Asset type: production macOS application icon, a single square 1024x1024 PNG for an app named Surf that turns an aluminum Siri Remote into a Mac pointer.

Primary request: A beautifully crafted, minimal macOS app icon combining a silver aluminum TV remote with one bold ocean wave. A rounded-square ocean-blue tile contains a simple sculptural turquoise curling wave across the lower half. One silver remote tilts gently up toward the right, riding the wave like a surfboard. The remote has a large circular dark clickpad near its top and only a few subtle dark buttons below it. The remote silhouette must be immediately recognizable, chunky enough to read at small Dock sizes. Subtle machined aluminum, soft studio lighting and restrained dimensional depth, like a polished native Mac utility icon. Clear, iconic composition, generous breathing room, no tiny decoration, no photorealistic scene.

Composition: straight-on orthographic view of the icon tile, centered on the canvas, tile approximately 84 percent of canvas width with smoothly rounded macOS-style corners. True transparent pixels outside the tile, including the corners, with only a very soft small contact shadow. All art remains within the tile.

Constraints: one finished icon only, no grid, no mockup, no text, no letters, no Apple logo, no watermark, no extra objects, no checkerboard baked into the image. Preserve actual alpha transparency outside the icon.
